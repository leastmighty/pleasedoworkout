# pleasedoworkout

**제운해(제발 운동 좀 해)** 안드로이드 앱의 공개 문서 저장소입니다.
개인정보처리방침과 소개 페이지를 GitHub Pages로 서비스합니다.

- 소개: <https://leastmighty.github.io/pleasedoworkout/>
- 개인정보처리방침: <https://leastmighty.github.io/pleasedoworkout/privacy.html>

> Public documents for the Android app **제운해 (Please Do Workout)** —
> privacy policy and landing page, served via GitHub Pages.

---

## 왜 저장소가 따로 있나

앱 소스는 **비공개 저장소**(`pleasedoworkout-app`)에 있습니다.
그런데 GitHub Free 요금제에서 **Pages는 공개 저장소에서만 동작**하고,
Play Console은 앱이 게시된 내내 개인정보처리방침 URL이 살아 있기를 요구합니다.

그래서 앱 소스와 공개 문서를 갈라 두었습니다.
이 저장소에는 **문서 두 장과 README뿐**이고, 앱 코드는 들어오지 않습니다.

전작 [제잠자](https://github.com/leastmighty/pleasegetsleep)도 같은 구조입니다.

## Pages 설정

`Settings → Pages → Source: Deploy from a branch → main / docs`
